# Changelog

## 0.3.0 - Cloud Foundation

### Added
- Supabase JavaScript client
- Local-first cloud synchronization manager
- Secure multi-shop PostgreSQL schema
- Customers, repairs, timeline, inventory, shops, and shop-member tables
- Row Level Security policies
- Realtime-ready customer, repair, and inventory subscriptions
- Environment-variable template
- Cloud setup instructions

### Important
- GadgetPOS still works locally without cloud credentials.
- Activating live cloud storage requires a Supabase project URL, publishable key, and running the included migration.

### Next
- Cloud login and shop selection
- Automatic sync indicator and conflict handling
- Full ticket editing
- Repair timeline and customer history workspace

## 0.2.0 - Customers and Check-In

### Added
- Customer creation and editing
- Customer search and deletion
- Repair history counts and last-visit display
- Searchable repair check-in
- iPhone 8 through iPhone 17 Pro Max model list
- Tablet, computer, and game-console choices
- IMEI, serial, passcode, color, part, technician, priority, estimate, due date, and notes
- Immediate Repair Board placement
